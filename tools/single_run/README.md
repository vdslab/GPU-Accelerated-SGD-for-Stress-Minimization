# ブラウザで単発実験

グラフと実験条件をプルダウンで選び、既存の `experiments/run_single.py` を1回実行するローカルページです。結果のコピー、JSONのコピー、before / after画像の表示に対応します。

## 起動

リポジトリ直下のターミナルでサーバーを起動します。拡張やVS Codeの設定は不要です。

```sh
python3 experiments/serve_single.py
```

ブラウザで `http://127.0.0.1:8765/` を開き、グラフと条件を選んで実行します。画面の「接続設定」にあるコピーアイコンで、起動コマンドをコピーできます。サーバーを後から起動した場合は「接続・再読み込み」を押してください。

ブラウザも同時に開く場合:

```sh
python3 experiments/serve_single.py --open
```

ターミナルのCtrl+Cで停止します。ポートが使用中なら `--port 8766` のように変更し、画面の「接続設定」でAPI URLをそのポートに変更します。

Live Serverで開く場合は、上のサーバーを起動したまま `tools/single_run/index.html` を開いてください。VS Codeの自動タスクや拡張設定は使用しません。

この実験ページではLive Serverの自動リロードを無効にしています。実験結果やビルド出力への書き込みで実行中の画面がリロードされることを防ぎます。HTML・JavaScript・CSSを編集した場合は手動でページを再読み込みしてください。実行状況と結果はページ内で更新されます。

Pythonの追加パッケージやフロントエンドのビルドは不要です。実験には既存実装と同じRust / Cargo・GPU環境が必要です。Atomic手法はmacOS / Metalを使用します。

## 保存内容

画面を閉じても、完了した実験結果はリポジトリ直下の `output/` に残ります。

```text
output/<graph>/<日本時間の日時>_<method>/
├── <日時>_0.png         # before
├── <日時>_1.png         # after
├── <日時>_info.txt      # 設定・計測時間・辺・最終座標
└── <日時>_result.json   # 設定・計測結果・出力パス
```

毎回新しいフォルダを作成するため、以前の結果を上書きしません。失敗時も設定とエラーを保存します。画像生成前に失敗した場合はPNGが揃わないことがあります。

左側で設定を選び、右上で結果、右下でbefore / after画像を確認します。「結果をコピー」は設定と計測結果の要約、「JSONをコピー」は保存されたJSON全文をコピーします。辺と座標を含む全文はTXTリンクから確認できます。画像はクリックすると画面内で拡大し、閉じるボタン・Esc・画像外のクリックで戻れます。

計測時間は、上段の「反復時間」「反復時間合計」「総計算時間」と、下段の内訳に分けて表示します。反復時間は平均を表示し、クリックすると反復ごとの値を確認できます。「計測区間の図を見る」で区間図を開けます。

| 表示 | JSONフィールド | 範囲 |
|---|---|---|
| 反復時間 | `iteration_times_ms` | CPU版は各反復のシャッフル・座標更新。GPU版は各反復のGPU計算passの実行時間合計 |
| 反復時間合計 | `iteration_total_time_ms` | 各反復の計測値の合計 |
| 総計算時間 | `total_compute_time_ms` | 入力読込開始からCPU座標取得までの実測経過時間（A→F） |
| 前処理時間 | `preprocess_time_ms` | 入力読込、距離・初期座標・スケジュール・転送用データの準備 |
| 初期転送時間 | `upload_time_ms` | 初期データの書込みから利用可能になるまで。Metal共有メモリではCPUから共有バッファへのコピー |
| GPU準備時間 | `gpu_prepare_time_ms` | デバイス・pipeline・buffer等の準備 |
| SGD実行時間 | `sgd_time_ms` | 初期転送後から最終読戻し直前まで。CPUの生成・投入・待ちも含む（D→E） |
| 結果取得時間 | `readback_time_ms` | 最終座標の読戻しからCPU配列完成まで（E→F） |
| 描画時間 | `draw_time_ms` | CPU座標取得から最終配置の最初のGPU描画完了まで（F→G） |
| 総計算時間（描画込み） | `total_with_draw_time_ms` | A→G。総計算時間＋描画時間 |

CPU版ではGPU準備・初期転送・結果取得を表示しません。GPU timestamp非対応時は反復時間を未計測にし、CPU待機時間で代用しません。GPU計算pass内のメモリ待ち・バリアは反復時間に含み、pass間の空白は含みません。Metal版は1 compute encoderだけを含む各command bufferのGPU開始・終了時刻を使います。

描画時間はsolverとrendererで共通の単調時計を使った実測です。現在の別プロセス構成では中心化、stress評価、座標ファイル保存・読込、プロセス起動、描画準備もF→Gに含まれます。Afterを先に描画するため、Before画像生成は含みません。GPU描画完了後の画像読戻し・PNG保存・ブラウザへの転送と表示待ちも含みません。描画しない通常のCLI実行には描画項目を追加しません。

前処理とGPU準備は実装内の該当処理区間を集計します。実際の処理順は概念図と一部前後します。総計算時間は内訳から推定せず、実際の開始・終了間を測ります。旧フィールド（`iteration_time_ms`やcold/warm合計）は既存の実験集計用に維持します。旧recordに新しい値がなければ未計測と表示します。

区間図は `build_timing_diagram.py` から生成し、`timing-diagram.png` を配信します（再生成にはPillowとmacOSのヒラギノフォントが必要）。

`data/` 以下の `.mtx` を自動列挙します。追加したら「接続・再読み込み」を押してください。`data/v1_lcc/` も選択できます。Full手法ではpivotsを無効にします。warmupは0回、同時実行は1件です。Rustのビルドはすべての計測区間外です。入力は既存実装に従って最大連結成分を使用します。

プルダウンの括弧は「ノード数 / エッジ数」です。件数は入力グラフ全体を対象とし、エッジは自己ループと重複を除いた無向辺として数えます。最大連結成分に絞った後の件数は実験結果で確認できます。1MB以下のファイルは辺数を計数し、結果をメモリにキャッシュします。大きなファイルは起動・接続を待たせないよう先頭情報だけを読み、辺数を「未計数」と表示します。選択・実験はそのまま可能で、実行結果には使用したグラフの辺数が保存されます。

グラフ欄に名前を入力すると候補を絞れます。↑ / ↓とEnterでも選択できます。「リスト」を押すと右上に一覧を開き、左の検索欄を使ったまま名前をクリックして選択できます。「閉じる」で結果表示に戻ります。検索は大文字・小文字を区別せず、`v1` などの版名でも絞れます。

一覧の列はグラフ名・ノード・エッジ・v1・v2・v3です。同じ名前のグラフは一覧とプルダウンの両方で1件にまとめます。v1で使用したグラフはその入力ファイルを優先し、それ以外も実験で使用した入力を優先します。表示するノード・エッジ数は選ばれた入力の件数です。実験に使用した版を候補の隣に表示し、一覧の該当列に「◯」を付けます。同名の入力が複数の版で使われていれば、版の印を1行にまとめます。版の情報は `experiment_results/v*/config/` のmanifestから取得し、manifestがない版では `datasets.json` を参照します。今後v4以降を追加すると、接続・再読み込みで列も増えます。

ブラウザを再読み込みしたときは、同じAPIが起動していれば実行中の実験や直前の結果を再表示します。API再起動後も保存ファイルは `output/` から直接確認できます。

画像は白背景・薄いグレーの辺・紫→朱色→淡い黄色の頂点で描画します（sunset配色）。色は各連結成分の最小頂点IDからの最短ホップ距離を成分内で正規化した値です。同じ頂点ID・辺を持つbefore / afterは同じ色になります。SGDの座標・計測には影響しません。既存の保存画像は変更せず、次回の単発実行から適用されます。
