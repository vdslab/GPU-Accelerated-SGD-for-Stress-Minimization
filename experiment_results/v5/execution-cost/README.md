# GPU準備・SGD・読み戻しを含む比較

> 2026-11-09整理：初回＋大規模の集計。後続EX1/EX2は含めない。 [v5総覧](../README.md)。
> 保存状態：2026-11-08の容量整理で座標等は削除済み。以下の座標保存・復元の説明は実行当時の記録。数値結果・既存図表は保持。再描画には座標の再取得が必要。

ユーザー指定の合計A＝GPU準備＋SGD経過時間＋読み戻し。比較値B＝A＋初期転送。CPU側は同族CPUのSGD経過時間を使う。全て15反復の1実行あたりで、GPU準備・読み戻しは各1回加算し15倍しない。前処理・Stress評価・保存・描画は含めない。表の÷15は準備等を15反復に配賦した平均であり、毎反復GPUを初期化する意味ではない。

合計・CPU比をrunごとに先に計算し、同seed3回の中央値→5seedの中央値・最小最大で集計。**各成分の中央値を足した値ではない。** 大規模はseed各1回。再実行・新しい図の作成は行っていない。

## 前処理について

同族内の初期配置・入力、およびSparseのpivot・距離・制約等のfingerprintは一致する。CPU/Atomic Sparseは共有の参照実装で制約一覧を作り、RoundRobin Sparseは同等の制約を省メモリ形式に組み立てる独立実装である。計算内容・結果の同等性と、実装・前処理時間の同一性は区別する。GPU固有のスケジュール/データ構築（method_setup_time_ms）は今回のA/Bには含めていないため、全GPU追加費用や処理全体を包含した値とは呼ばない。描画はこの実験では未計測で、同時間であると実証していない。
