# Gitに保存する結果とローカル保持データ

2026-11-08時点のv5・追加実験・診断結果を保存する。

## Gitへ保存するもの

- 実験・集計・図生成・診断コード、実行時ソースのスナップショット。
- 入力出典・入力ハッシュ、seed、反復数、パラメータ、実行順、機材・バイナリハッシュ。
- 本測定・warmup・validationのJSON記録、コマンド、ログ、圧縮検証manifest。ローカルの.git/info/exclude対象ディレクトリでも、これらの記録は明示的に追加する。
- 生の計測値CSV/JSONL、階層集計、厳密Stress再評価の値と出典、検証結果、考察。
- 論文用チャートPNG・PDF、Obsidianへ出力したレポートのリポジトリ側コピー。
- EX1（W=T）、EX2（RR128、全計時項目）、CPU/Atomic/RR128チャート集、128対1024比較。

## ローカルに保持し、Gitへ入れないもの

- 圧縮済み初期・最終座標、vertex-map、共有辺テンプレート。v5全体の配置payloadは約67GBで、一部は単一ファイルだけで100MBを超える。
- 実行バイナリ、Cargo target、距離行列キャッシュ、実行ロック、Instrumentsの巨大な.trace/.gputrace。
- ダウンロード・正規化入力（既存方針どおりdata/は対象外）。入力の出典・ハッシュは計画やmanifestに保存する。

上記のローカルファイルは削除しない。Gitへ保存されたarchive manifestには元ファイル・圧縮ファイルのハッシュと検証結果があるが、**manifestだけで元の座標ファイルを復元できるわけではない**。Atomicのような非決定的方式の最終座標を含め、保存座標が必要な再評価・再描画にはローカルpayload、または別途の大容量アーカイブが必要。

図表の再描画は保存済み集計から可能。最終配置から再評価する処理は、ローカルの圧縮座標が残っていることを前提とする。絶対パスは測定時の出典であり、別環境では対応するローカル入力・payloadへのパスを調整する。
