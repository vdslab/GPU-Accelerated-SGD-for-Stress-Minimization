## 言える範囲

複数手法と共通CPU前処理の両方が遅くなったこと、現在swap/圧縮メモリを保持していることは確認できた。一方、現在の5秒ではswap I/Oは0であり、seed 1実行当時にswapや外部プロセスが遅延を引き起こしたという直接の同時計測証拠はない。成功CPUのtime -l page faultsは両seedで18、RRも両seedで307、swapsはいずれも0で、これもsystem-wide swapの関与を証明・否定する資料には足りない。

したがって、システム全体の状態や共有資源による影響は調査候補だが、原因は未特定。これらの結果を「Atomicのdeadlock」又は「swapが原因」とは扱わない。
