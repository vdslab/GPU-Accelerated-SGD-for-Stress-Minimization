## ADDED Requirements

### Requirement: 独立した CPU 疎ベースライン
システムは、Matrix Market 形式のグラフを読み込み、GPU を使用せず実行できる独立した Rust crate として、`baseline-sparse-sgd-non-gpu` を提供しなければならない（MUST）。

#### Scenario: 正常なグラフを使用した実行
- **WHEN** 設定された Matrix Market 入力パスを使用して実行ファイルを起動したとき
- **THEN** グラフを読み込み、CPU 処理だけで Sparse SGD を完了する

### Requirement: ランダム化 max-min pivot 選択
システムは、最初の頂点をランダムに選び、以降は選択済み pivot のうち最も近いものまでの距離が最大となる頂点を繰り返し選択する、ランダム化 max-min 最短路サンプリングにより、要求数以下の重複しない pivot を選択しなければならない（MUST）。

#### Scenario: 空でないグラフから pivot を選択する
- **WHEN** 1以上かつ頂点数以下の pivot 数を要求したとき
- **THEN** 有効な頂点番号から、指定数と同数の重複しない pivot を返す

#### Scenario: 頂点数を超える pivot を要求する
- **WHEN** 要求された pivot 数が頂点数を超えるとき
- **THEN** 各頂点を最大1回だけ選択し、無効な頂点番号を生成しない

### Requirement: 疎な最短路制約
システムは、選択した pivot から重みなし最短路距離を計算し、到達可能な頂点と pivot の組および全グラフ辺から、端点を正規化して重複を排除した制約を構築しなければならない。各制約の重みは `1 / d_ij^2` とし、グラフ辺の目標距離は1としなければならない（MUST）。

#### Scenario: 連結グラフの制約を構築する
- **WHEN** `n` 頂点と `h` 個の選択済み pivot を持つ連結グラフの制約を準備したとき
- **THEN** 自己対でない各頂点と pivot の関係を最大1回だけ表し、すべてのグラフ辺を目標距離1で表す

#### Scenario: 非連結成分を処理する
- **WHEN** ある頂点が選択済み pivot から到達不能であるとき
- **THEN** その頂点と pivot の関係について、無限値または番兵値を目標距離に持つ制約を生成しない

### Requirement: Sparse SGD の座標更新
システムは、アニーリングの各段階で制約順序をランダム化し、`mu = min(w_ij * eta, 1)` および `d_ij` から導出した対称なストレス最小化変位を使用して、両端点の座標を更新しなければならない（MUST）。

#### Scenario: 1つの有限な制約を処理する
- **WHEN** 有限かつ正の目標距離と学習率を持つ制約が、異なる位置にある2点を結んでいるとき
- **THEN** 両端点を大きさが等しく向きが反対の変位で移動し、両座標を有限値に保つ

#### Scenario: 一致する座標を処理する
- **WHEN** 制約の両端点が同一座標にあるとき
- **THEN** 0除算を回避し、有限な座標を生成する

### Requirement: アニーリングとレイアウト初期化
システムは、ランダムな二次元初期レイアウトと、既存 CPU SGD ベースラインと互換性のある指数減衰学習率スケジュールを生成し、任意指定により最終レイアウトを中心化しなければならない（MUST）。

#### Scenario: 最適化実行を準備する
- **WHEN** 有効な反復回数、epsilon、pivot 数、中心化パラメータを指定したとき
- **THEN** 準備済み状態に、各頂点につき1つの二次元座標と、各反復につき1つの学習率を含める

#### Scenario: 結果を中心化する
- **WHEN** 中心化を有効にし、空でないレイアウトの最適化が完了したとき
- **THEN** x 座標と y 座標の平均を、浮動小数点の許容誤差内でともに0とする

### Requirement: ベースライン互換の結果ファイル
実行ファイルは、グラフのメタデータ、辺の組、座標、データセット名、タイムスタンプ、処理段階の末尾番号を含む既存ベースラインのテキスト構造を使用して、ランダム化された初期レイアウトと処理後レイアウトを書き出さなければならない（MUST）。

#### Scenario: 最適化実行を完了する
- **WHEN** Sparse SGD が正常に完了したとき
- **THEN** 出力ディレクトリへ、ファイル名に `baseline-sparse-sgd-non-gpu` を含み、`-0.txt` で終わる初期ファイルと `-1.txt` で終わる処理後ファイルを作成する
