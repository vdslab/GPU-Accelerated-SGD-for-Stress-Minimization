# GPU Visualization

## Purpose

Sparse SGDなどが生成した座標結果を、大規模グラフでも有界な評価とGPU描画でPNGへ可視化する契約を定義する。

## Requirements

### Requirement: 規模に応じたストレス評価

visualizerは`auto`、`exact`、`sampled`、`off`のストレス評価モードを提供しなければならない（MUST）。引数を指定しない通常実行は`auto`を使用し、8,000頂点以下では厳密値、それを超える入力では有界な標本化推定を使用しなければならない（MUST）。

#### Scenario: 小規模入力を通常実行する

- **WHEN** 8,000頂点以下の有効な結果TXTをモード指定なしで読み込む
- **THEN** 従来と同じ定義の厳密ストレスを計算し、`Stress`として表示する

#### Scenario: 大規模入力を通常実行する

- **WHEN** 8,000頂点を超える有効な結果TXTをモード指定なしで読み込む
- **THEN** 全頂点始点の厳密計算を実行せず、既定64始点の標本化ストレスを計算する
- **AND** `Approx stress`、標本数、seed、計算時間を表示する

#### Scenario: 厳密計算または省略を明示する

- **WHEN** 利用者が`--stress exact`または`--stress off`を指定する
- **THEN** 前者では大規模入力の高コスト警告付きで厳密計算し、後者ではBFSによるストレス計算を行わずに描画を続行する

### Requirement: 再現可能な標本化ストレス

標本化ストレスは、指定された標本数とseedに対して重複しない始点集合を決定的に選び、無向頂点対の厳密ストレス総和を推定しなければならない（MUST）。計算量は標本数を`K`として`O(K(|V|+|E|))`、BFS作業メモリは`O(|V|)`に収めなければならない（MUST）。

#### Scenario: 同じ条件で繰り返す

- **WHEN** 同じ入力、標本数、seedで`sampled`を2回実行する
- **THEN** 選択始点と表示される近似ストレスは一致する

#### Scenario: 標本数を変更する

- **WHEN** 利用者が`--stress-samples K`で有効な正整数を指定する
- **THEN** `min(K, |V|)`個の重複しない始点を使用し、実際に使用した個数を表示する

#### Scenario: 全頂点を標本にする

- **WHEN** 連結した小規模グラフで標本数が頂点数以上に設定される
- **THEN** 標本化式の結果は浮動小数点許容誤差内で厳密ストレスと一致する

### Requirement: インデックスによるGPU辺描画

visualizerは正規化済みノード座標を共有vertex bufferへ一度格納し、辺端点を`u32` index bufferへ格納してindexed line-listとして描画しなければならない（MUST）。辺ごとに両端の浮動小数点座標を複製したCPU/GPUバッファを作成してはならない（MUST NOT）。

#### Scenario: 全辺を通常描画する

- **WHEN** 有効な結果TXTを辺数上限なしで描画する
- **THEN** 入力の全辺をindex bufferへ格納し、全辺を描画する

#### Scenario: GPU制限または不正辺を検出する

- **WHEN** 必要なvertex/index bufferが選択GPUの上限を超える、または辺が存在しない頂点を参照している
- **THEN** GPU描画開始前に必要サイズと上限、または該当する辺・端点を含む診断エラーを返す

### Requirement: 大規模グラフ向けLOD

visualizerは出力画素数と頂点数に応じてノード半径を自動選択し、大規模入力で過度な重なりを避けなければならない（MUST）。利用者は`--node-radius`で半径を上書きできなければならない（MUST）。

#### Scenario: 25万頂点を自動設定で描画する

- **WHEN** 2048×2048画像へ25万頂点を自動ノード半径で描画する
- **THEN** 4pxより小さい半径を選び、選択値を表示する

#### Scenario: ノード半径または辺数上限を上書きする

- **WHEN** 利用者が`--node-radius`または総辺数より小さい`--max-edges N`を指定する
- **THEN** 指定半径を使用し、後者では決定的に選択したN本以下の辺を描画して描画辺数・総辺数・間引きを表示する

### Requirement: 入力検証と段階別診断

visualizerは既存の結果TXT形式を読み込み、利用可能なnode/edge countを事前確保へ使用し、座標数、座標の有限性、辺端点をGPU初期化前に検証しなければならない（MUST）。主要処理段階の所要時間と処理規模を表示しなければならない（MUST）。

#### Scenario: 既存結果を読み込む

- **WHEN** Sparse SGDまたはRR-SGDが出力した既存形式の有効なTXTを指定する
- **THEN** 形式変換なしで読み込み、頂点数と辺数を表示してPNGを生成する

#### Scenario: 段階別時間を報告する

- **WHEN** 描画が正常に完了する
- **THEN** 読込、ストレス評価、GPU準備・転送/描画/読戻し、PNG保存、合計の時間を区別して表示する

### Requirement: 25万頂点級の受入性能

visualizerは25万頂点・約200万辺の連結グラフを通常設定で処理するとき、厳密全点対ストレス計算を実行せず、辺座標を展開せず、GPU validation errorまたはメモリ不足を起こさず2048×2048 PNGを生成できなければならない（MUST）。

#### Scenario: 論文規模相当のfixtureを描画する

- **WHEN** 25万頂点・190万辺以上200万辺以下の決定的fixtureを`--stress auto`で対応GPU上に描画する
- **THEN** 標本化ストレス経路とindexed edge drawingを使用してPNG生成を完了し、全段階の時間、描画頂点数・辺数、ストレス条件を記録する

#### Scenario: 小規模互換性を確認する

- **WHEN** 既存の小規模回帰fixtureを新旧の厳密ストレス実装で評価する
- **THEN** 厳密ストレス値は定めた浮動小数点許容誤差内で一致し、出力PNGの寸法と描画対象の頂点数・辺数も一致する
